# Local videos for docs

Put your MP4 files in this folder and reference them in docs as `/videos/<file-name>.mp4`.

Recommended naming (one per section):
- intro-overview.mp4
- auto-script-walkthrough.mp4
- auto-analysis-overview.mp4
- nfr-strategy-overview.mp4
- governance-overview.mp4
- settings-overview.mp4

Guidelines:
- Use MP4 (H.264 video + AAC audio) for best browser support.
- Keep each file reasonably compressed.
- In docs, use `<video controls preload="metadata">` to reduce initial page load.
